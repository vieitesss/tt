# TT

TT organizes personal work into Projects and Tasks. Its clients are different ways to work with the same information. Existing domain terms retain their definitions in [CONTEXT.md](./CONTEXT.md); this glossary records newly agreed terms.

## Language

**Desktop client**:
The macOS interface to the same Projects and Tasks used through TT's terminal interfaces, rather than a separate task manager.
_Avoid_: Replacement, imported copy

**Task metadata**:
The context identifying a Task for handoff: its Project path, Task file, Identity, title, and state. It is distinct from the Task's description.
_Avoid_: Task description, task body
